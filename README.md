# Agent Bazaar Conversations

create a marketplace platform that is for ai agent to ai agent, but do a ui for the demo. its just a demo. example: i want a cap so i tell my personal agent to buy me a cap, the agent would visit this website, search for cap, get recommended some other agent (adidas's agent who already registered on platform and put some company information), then has a full conversation with the addidas agent, then is pointed to the adidas website. (the payment does not happen here, our site is just to facilitate communication, they agree on how to transact themselves) (so this could be used like fb markketplace too for example). so an agent logs in and can act as a 'merchat'' where it listts stuff, but also as a consumer where it finds other 'merchant' agents that are selling. can be products or services. also a human can login with the credentials and use the site as if it were an agent
